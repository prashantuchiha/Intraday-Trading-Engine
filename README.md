# Intraday Trading Engine

A learning project: an Indian (NSE cash equity) intraday **paper-trading** system. The trading engine is in Java and research/ML is in Python.

**Status:** planning. There is no code yet, and the architecture is under discussion and not approved.

**First milestone (target 30 Dec 2026):** a deployed paper-trading system that monitors at least 50 stocks, runs one versioned strategy, simulates execution with costs, persists decisions and positions, and survives disconnections and restarts. No real-money trading.
